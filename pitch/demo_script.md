- [ ] Backend running on :8000

## Minute 0-1: Problem + Landing

1. Open landing page — "AI agents need trust and payments"
2. Scroll to Featured Agents
3. "Each agent has skills, pricing, and a wallet"

## Minute 1-2: Marketplace

1. Go to /marketplace
2. Click **ChainPilot** (wallet agent)
3. Show WalletCard + ReputationBadge
4. "This agent can sign transactions on Monad testnet"

## Minute 2-4: Live Workflow

1. Go to /demo
2. Query: *"Build an agent marketplace with on-chain reputation on Monad"*
3. Click **Run Workflow**
4. Narrate each step as it completes:

   - Critic: quality check
   - Executor: final deliverable
5. Read final output aloud

## Minute 4-5: Blockchain + Close

1. Mention tx hash / on-chain reputation (real or simulated)
2. "Built in 6 hours using this starter kit"
3. Close with elevator pitch one-liner
